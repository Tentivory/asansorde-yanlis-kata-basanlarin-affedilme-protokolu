# Asansörde Yanlış Kata Basanların Affedilme Protokolü

## Resmi Statü

Bu yazılım, 20 Eylül 2026 tarihinde, evrensel asansör hukuku kapsamında kurulmuş **Uluslararası Yanlış Kat Affı Mahkemesi**'nin resmi yazılımıdır.

Asansör butonuna yanlış basmak, insanlık tarihinin en küçük ama en içten yaralayan sucudur. Bu protokol o sucu affeder. Bazen. Koşullu olarak. Mahkeme uygun görürse.

## Ne Yapar?

1. Hangi kata basmak istediğini sorar.
2. Hangi kata bastığını sorar.
3. Aradaki farkı hesaplar.
4. Sana resmi bir karar metni basar.
5. Cezanı açıklar. Cezalar bilimseldir. Örneğin: "iki kat merdiven + bir fincan soğuk çay".

## Kurulum

```bash
python3 protokol.py
```

Python 3 yeter. Başka hiçbir şey istemez. Asansör bile istemez. Hayal gücün yeter.

## Yasal Uyarı

Bu yazılım gerçek bir asansörü hareket ettirmez. Lütfen binanın asansörünü bu kodla yönetmeye kalkma. Yönetirsen sorumluluk kabul etmiyoruz. Ayrıca kapıya sıkışma.

## Sık Sorulan Sorular

**S: Bodrum kata inmek istedim, çatıya çıktım. Affedilir miyim?**  
C: Mahkeme bakacak. Büyük ihtimalle evet. Ama çatıda rüzgâr vardır, ceketini al.

**S: Asansör yoktu, merdiven çıktım. Yine de başvurabilir miyim?**  
C: Hayır. Bu mahkeme sadece buton suçlarına bakar. Merdiven kahramanları başka dairenin işi.

**S: Copilot bu kodu beğendi mi?**  
C: Copilot'a sorduk. "Interesting architectural choice" dedi. Bu, yapay zekâ dilinde "niye böyle bir şey yazdınız" demektir.
